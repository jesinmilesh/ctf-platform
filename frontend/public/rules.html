BATTLEFIELD CODE // DIRECTIVE 01

Rules of Engagement

Operatives are required to strictly adhere to the engagement protocols. Violations result in automatic disqualification.

01 // TARGET ISOLATION & INFRASTRUCTURE PROTECTION

Attacking the CTF scoring infrastructure, game servers, or other participants’ systems is strictly prohibited. You may only target designated mission hostnames and allocated challenge container sandboxes.

02 // NO COLLUSION & FLAG SHARING

Squads must independently capture flags. Distributing flags, solutions, or clues to rival squads or public channels before the battlefield closure is forbidden.

03 // BRUTE FORCE & RATE LIMITING

Do not conduct automated brute-force attacks against flag submission endpoints or administrative endpoints. A rate limiter is active. Malicious traffic bursts will result in IP blacklisting.

04 // FLAG FORMAT STANDARD

All valid flags conform to the competition standard pattern:

XploitXβ{your_captured_flag_string}

05 // DYNAMIC SCORING DECAY & TIE BREAKING

Challenges start with their base value (e.g. 500 XP). Each subsequent solve decays the point value smoothly towards the floor value. Ties on the leaderboard are resolved chronologically by whoever achieved the score first.
